## 0. 공통 원칙

- 어르신이 읽기 쉽게 **한 문장은 짧게, 한 화면에 한 가지**만 안내한다.
- 앱의 기존 말투(`~해요`, `~해 주세요`)를 따른다.
- 확인하지 않은 정보는 만들어 쓰지 않고 **"확인 필요"**로 둔다.
- 건강 효과·복지 자격을 단정하는 표현을 쓰지 않는다.
- 성장·포인트·아이템·영상·커뮤니티 관련 문구는 만들지 않는다(후속 범위).

## 1. 생활 이용 가이드

### 1.1 가이드 1 — 글자 크게 보기 (완결본)

- **출처**: 오늘동행 앱 설정 화면 (글자 크기: 보통·크게·아주 크게)
- **확인일**: 2026-11-11
- **그림**: 각 단계마다 실제 앱 화면 캡처 1장, 누를 곳을 빨간 동그라미로 표시

| 단계 | 그림 | 화면 문장 | 읽어주기 문장 |
|---|---|---|---|
| 1 | 아무 탭의 화면, 오른쪽 위 톱니바퀴 표시 | 화면 오른쪽 위의 **파란 톱니바퀴**를 눌러요. | 화면 오른쪽 위에 있는 파란 톱니바퀴를 눌러 주세요. |
| 2 | 설정 화면, '글자 크기' 영역 표시 | **글자 크기**에서 원하는 크기를 골라요. | 글자 크기에서 보통, 크게, 아주 크게 중 하나를 골라 주세요. |
| 3 | '크게' 또는 '아주 크게' 선택된 모습 | **크게**나 **아주 크게**를 누르면 바로 바뀌어요. | 크게나 아주 크게를 누르면 글자가 바로 커져요. |
| 4 | 미리보기 문장 표시 | 아래 **미리보기 글자**로 잘 보이는지 확인해요. | 아래 미리보기 글자가 잘 보이는지 확인해 주세요. |
| 5 | 왼쪽 위 뒤로가기 표시 | 다 되었으면 **왼쪽 위 화살표**로 돌아가요. | 다 되었으면 왼쪽 위 화살표를 눌러 처음 화면으로 돌아가요. |

- **완료 화면**: "다 했어요! 이제 글자가 크게 보여요."
- **버튼**: `[이전]` `[다음]` (마지막 단계는 `[다 했어요]`), 모든 단계에 `[읽어주기]`

### 1.2 가이드 2 — 읽어주기 켜기 (선택, 같은 형식)

| 단계 | 화면 문장 |
|---|---|
| 1 | 오른쪽 위 **파란 톱니바퀴**를 눌러요. |
| 2 | **음성 안내 사용**을 켜요. |
| 3 | **음성 미리 듣기**를 눌러 소리가 나는지 확인해요. |
| 4 | 이제 화면의 **스피커 버튼**을 누르면 읽어드려요. |

- 소리가 안 날 때: "휴대폰의 소리 크기와 한국어 음성 설정을 확인해 주세요."

### 1.3 가이드 화면 공통 문구

| 위치 | 문구 |
|---|---|
| 가이드 목록 제목 | 생활 도우미 |
| 목록 안내 | 궁금한 사용법을 골라 보세요. |
| 목록 하단 버튼 | `[알고 싶은 내용 남기기]` |
| 가이드가 없을 때 | 아직 준비된 안내가 없어요. 알고 싶은 내용을 남겨 주세요. |

### 1.4 주제 요청 → 관리자 검수 → 게시 흐름

**사용자 화면 (앱)**

| 단계 | 문구 |
|---|---|
| 요청 화면 제목 | 알고 싶은 내용 남기기 |
| 주제 고르기 | 어떤 내용이 궁금하세요? `[휴대폰 사용]` `[이 앱 사용]` `[외출·교통]` `[기타]` |
| 한 줄 입력 | 어려운 점을 짧게 적어 주세요. (예: 사진 보내는 법을 모르겠어요) |
| 개인정보 안내 | 이름·전화번호·주소는 적지 말아 주세요. |
| 보내기 버튼 | `[보내기]` |
| 보낸 뒤 | 잘 받았어요. 확인해서 안내를 준비할게요. |

**관리자 상태 (관리자 웹)**

`접수` → `검토 중` → `게시` 또는 `보류(사유 기록)`

**관리자 검수 체크리스트**

- [ ] 단계는 6개 이하, 한 단계에 문장 1~2개
- [ ] 단계마다 그림 1장, 누를 곳 표시
- [ ] 출처와 확인일 기록 (앱 기능은 앱 버전, 외부 정보는 공식 출처)
- [ ] 지역 번호·절차 등 외부 정보는 공식 자료로 확인한 것만 사용
- [ ] 요청 글에 개인정보가 있으면 게시 전 삭제
- [ ] 읽어주기 문장이 화면 문장과 같은 내용인지

## 2. 캐릭터 달성 규칙 (ADD-07)

### 2.1 인정하는 활동 (제안 — 팀 확인 필요)

| 활동 | 인정 시점 | 하루 인정 |
|---|---|---|
| 식사 기록 | 음식명·시간을 확인하고 `[기록하기]`를 눌렀을 때 | 끼니별 1회 |
| 요리 완료 | '한 단계씩 따라 만들기'의 마지막 단계에서 `[다 만들었어요]`를 눌렀을 때 | 레시피별 1회 |
| 생활 가이드 | 가이드 마지막 단계에서 `[다 했어요]`를 눌렀을 때 | 가이드별 1회 |

### 2.2 규칙

- **본인이 직접 누른 확정 버튼만** 인정한다. 화면을 열거나 사진을 고르는 것만으로는 인정하지 않는다.
- **중복**: 같은 활동·같은 대상은 하루 1회만 반응한다. 이미 인정된 활동을 다시 눌러도 반응하지 않는다.
- **취소**: 기록을 삭제하거나 완료를 취소하면 그날의 달성 표시도 함께 취소한다. 취소할 때는 캐릭터가 반응하지 않는다.
- **끄기**: 설정에서 `캐릭터 반응` 스위치로 끈다. 끄면 반응·달성 표시가 모두 보이지 않는다.
- **표시 시간**: 반응은 2~3초 뒤 자동으로 사라지고, 다른 버튼을 가리지 않는다.

### 2.3 반응 문구 예시

| 상황 | 문구 |
|---|---|
| 앱을 켰을 때 | 오늘도 반가워요! |
| 식사 기록 | 오늘 식사를 기록했어요. 잘하셨어요! |
| 요리 완료 | 요리를 끝까지 해냈어요! |
| 가이드 완료 | 새로운 사용법을 익혔어요! |
| 설정 스위치 설명 | 활동을 마치면 캐릭터가 짧게 칭찬해 줘요. |

- 쓰지 않는 표현: "건강해졌어요", "영양이 좋아졌어요"처럼 효과를 단정하는 말, 포인트·레벨·보상 관련 말

## 3. 가족에게 공유 (ADD-03)

### 3.1 공통 문구

| 위치 | 문구 |
|---|---|
| 버튼 | `[가족에게 보내기]` |
| 미리보기 제목 | 이 내용이 보내져요 |
| 미리보기 안내 | 보내기 전에 내용을 확인해 주세요. |
| 개인정보 안내 | 이름·나이·사는 곳·건강 상태는 보내지 않아요. |
| 버튼 | `[보내기]` `[취소]` |
| 보내기 누른 뒤 | 보낼 앱(카카오톡 등)과 받는 사람을 골라 주세요. |
| 취소했을 때 | (안내 없이 원래 화면으로 돌아감) |
| 실패했을 때 | 보내지 못했어요. 다시 한번 눌러 주세요. |
| 보낼 앱이 없을 때 | 보낼 수 있는 앱이 없어요. 카카오톡이나 문자 앱을 확인해 주세요. |

- 커뮤니티 게시(후속)와 헷갈리지 않도록 버튼 색과 문구를 다르게 한다.

### 3.2 보내는 내용 (텍스트 기본)

| 대상 | 포함 | 제외 |
|---|---|---|
| 레시피 | 메뉴 이름, 재료, 조리 순서, 출처 | 사용자 정보 |
| 식단표 | 날짜, 끼니별 메뉴 이름 | 건강 상태·알레르기·추천 이유 |
| 장보기 | 재료 이름·분량, 구매 여부 | 사용자 정보 |
| 복지 안내 | 제도명, 지원 내용, 문의처, 공식 링크, 기준일 | 나이·가구·소득 정보, 진행 메모 |

**메시지 끝 문구**: "오늘동행 앱에서 보냈어요."

## 4. 복지 안내 카드 (ADD-02)

### 4.1 카드 항목 순서

| 순서 | 항목명 | 내용 | 정보가 없을 때 |
|---|---|---|---|
| 1 | 제도 이름 | 공식 사업명 | — |
| 2 | 누가 받을 수 있나요 | 공식 지원 대상·선정 기준 원문 요약 | 주민센터 확인 필요 |
| 3 | 무엇을 도와주나요 | 지원 내용 | 주민센터 확인 필요 |
| 4 | 준비할 것 | 공식 안내에 나온 준비물 | 준비물은 주민센터에 확인해 주세요 |
| 5 | 어디에 물어보나요 | 문의처·신청 경로(전화, 방문, 온라인) | 가까운 주민센터에 문의해 주세요 |
| 6 | 출처·확인일 | 공식 출처 이름, 자료 확인 날짜 | (항상 표시) |

### 4.2 고정 안내 문구

- 카드 위: **"이 안내는 신청 자격을 판정하지 않아요. 받을 수 있는지는 주민센터나 담당 기관에서 확인해 주세요."**
- 카드 아래: "자료 확인일: YYYY-MM-DD. 내용이 바뀌었을 수 있어요."
- 큰 글씨 보기 버튼: `[주민센터에 보여주기]` → 카드를 화면 가득 크게 표시

### 4.3 저장·진행 메모

| 위치 | 문구 |
|---|---|
| 저장 버튼 | `[관심 복지에 저장]` / 저장 후 `[저장됨]` |
| 저장했을 때 | 관심 복지에 저장했어요. |
| 저장 해제 | 관심 복지에서 뺐어요. |
| 진행 메모 단계 | `[알아봤어요]` → `[문의했어요]` → `[신청했어요]` |
| 메모 안내 | 내가 기록하는 메모예요. 실제 신청 결과는 담당 기관에서 확인해 주세요. |
